# 星穹策略｜抽卡与三队规划

基于《崩坏：星穹铁道》的当前阵容、通关成绩、目标行动值（AV）和抽卡预算，估算未来 1–12 个版本内三支现有队伍的维护成本。结果包含每队的战力缺口、预计投入、逐版达标情况及独立的换队门槛。

## 快速开始

用浏览器打开 `index.html`。网页的主要计算可离线运行，无需安装依赖。首次打开时显示「第一队」「第二队」「第三队」，阵容、挑战目标、成绩和抽卡库存留空。可以从「预算」导入已有的规划 JSON，也可以按以下顺序填写。

| 步骤 | 怎么填 |
| --- | --- |
| **① 预算** | 填当前星琼和限定专票，选择收入档位与规划版本数。必要时使用自定义版本收入。 |
| **② 成绩** | 在「配置四名角色」中填写星魂、光锥及叠影、遗器和面板。每队选择高难模式、目标 AV 和成绩录入方式。异相仲裁还要选择具体的骑士关或王棋。 |
| **③ 遗器** | 在角色配置中录入要刷的遗器部位、当前主副词条和目标条件，再设定规划期投入遗器的体力比例，默认 100%。多个目标若来自同一副本，共享该副本的全部遗器体力。涉及多个副本时，分别填写体力占比，合计 **100%** 后点击「应用体力分配」。 |
| **④ 预测** | 核对关卡血量增长率和规划期累计涨幅。已有自己的预测时，可在高级参数中覆盖。 |
| **⑤ 结果** | 点击底部浮窗的「生成规划」。先看三队的维护成本与合计，再查看逐版预算、逐金候选及每队的换新门槛。 |

面板可以手填，也可以上传游戏、米游社或微信工坊截图进行 OCR，从识别结果中选择要应用的字段。中文 OCR 首次使用需要联网下载模型，图片在浏览器本机处理。

### 行迹怎么填

- 技能等级留空时，网页按未加魂的满级技能计算，再叠入现有星魂提供的等级。
- 手填或导入的技能等级视为游戏显示等级，已包含当前星魂加级。网页只追加新星魂带来的等级差。
- 额外行迹和属性节点留空时按已解锁处理。选为「未解锁」的节点按该状态处理。手填的实战外面板数值优先。
- 已接入战斗规则的升级会自动使用内置数据计算。展开候选详情中的「可选校准」可添加同队、同关、且只改这一项的前后通关 AV。

## 怎么读结果

**战力缺口。** 模型用「当前成绩 AV ÷ 目标 AV × 未来关卡负荷指数 − 1」估算总输出缺口。以当前用时 350 AV、目标 250 AV、下一版关卡负荷增加 2.9% 为例，未计遗器时需要提升 **44.06%**。遗器的期望收益按倍率从需求中扣除。未通关且只记录了已用 AV 时，结果给出需求下界。选择「不填」录入方式时，模型按刚好耗尽目标 AV 估算。

**逐金候选。** 每行对应一次星魂升级或一次光锥更换。默认每队显示前五步，展开可查看完整顺序。每一步从已经满足前置条件的候选里选收益最高的一项，选中后才解锁后续星魂。缺少收益数据的可抽项在没有已知收益候选时列入，后续累计收益标为待补全。依赖前置星魂的候选会标明起始星魂，成本搜索会计入这些前置步骤。例如 E1 增伤 10%、E2 再增加同乘区增伤 20 个百分点，E2 相对 E1 的边际提升是 `1.30 ÷ 1.10 − 1 ≈ 18.18%`。

**维护汇总。** 每队显示期末血量涨幅、扣除遗器期望后所需的提升、建议补金顺序及成本。三队成本相加得到维护总需求，逐版本行动表按现有预算安排投入。若部分版本仍未达标，合计代表已找到的投入。

| 名称 | 含义 |
| --- | --- |
| **等价金** | 用于汇总长期预算。限定角色按 **93.75 抽**计为 1 等价金，限定光锥按约 **66.84 抽**计为约 0.71 等价金。 |
| **实际限定件数** | 需要获得的角色本体、星魂或专锥件数。自定义方案对比另列平均抽数与按当前垫抽、大保底计算的保底预算。 |
| **单金最低提升** | 给定预算件数时，要填平缺口所需的平均收益。实际选择看候选的逐步收益和前置成本。 |

### 怎样填写换队参考

在原队对应位置用中文、拼音或首字母搜索换入角色。一次可选择多个位置。点击「配置换入角色并比较」，为换入角色填写实际面板、星魂、光锥和叠影。沿用角色直接读取原队配置。每名换入角色可标为已拥有或未拥有。未拥有时，空白面板按基础属性加随机分配的 20 档相关副词条估算，手填数值优先。换人表先计每个未拥有角色的 1 金本体成本。同关 AV 或整队提升用于确定换人收益，多人换人以整组计。

保存后比较原队与最新两次换人方案。各表按当前可抽项目的全队边际收益排序，并在选中后解锁后续星魂。一次换多名角色仍只生成一张表。基础强度未知时会显示当前关卡的达标 AV 门槛。同关 AV 或相对全队提升可用于估算期末缺口。

「导出全部方案表格」包含该队原阵容及全部已存方案。换人记录也随规划 JSON 导入导出。

## 保存配置与导出报告

- 在「预算」中点 **导出本次填写 JSON**，下载可继续编辑的配置，包括各队换队收益和备注。下次打开网页后点「导入之前的 JSON」恢复。
- 在结果汇总中点 **导出补金报告**，下载 `星穹策略_补金报告.html`。这是一份可单独打开和打印的报告，包含三队维护汇总，以及各队的换新门槛、折算结果和备注。

## 数据与估算边界

- **关卡预测**以历史标称血量作为负荷代理。怪物机制、波次和环境增益会改变结果。异相仲裁按骑士一、二、三和王棋分别预测。若站点提供同目录的 `hsr_updates.json`，网页会尝试读取周更数据，离线时使用内置样本。
- **维护队**优先搜索规划期最大缺口所需的最低成本路线，完整搜索至 **5 件升级**。部分原始效果仍缺运行规则，任意换入队友后的完整循环也尚未覆盖。最低成本只在已建模候选范围内成立。伤害占比、覆盖率、回能和出手次数包含模型估算。
- **遗器收益**按掉落与词条概率模型计算期望值，实际收益随刷取结果变化。规划报告会注明未达标版本和逐版预算缺口。

数值快照来源见 [TurnBasedGameData](https://github.com/DimbreathBot/TurnBasedGameData)。异相仲裁历期数据可查 [星穹智库](https://sr.appfeng.com/challenge/arb)。

遗器期望改善档数平摊到暴击主C的双暴、攻击和速度，击破队按击破特攻与速度 2:1 分配，其他辅助以速度为代理。预计属性先用于计算遗器收益；动态补金规则再以预计面板计算边际收益，实战校准沿用原值。属性伤害来自主词条切换，当前仅估算明确指定攻击球换指定属性伤害球的情形。

同一副本有多件已录入的遗器时，可在「同副本产物联动」选择主刷目标和计入的其他部位。联动默认计入，可整组关闭或逐件排除。联动部位与主刷共用该副本体力，各照当前装备与目标条件估算收益。设置随规划 JSON 保存。
